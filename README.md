## Inside The Scroll: EDA + Visualization Analysis Project

This project explores Gen Z social media usage patterns and their association with addiction levels and mental well-being.

## ✅ Task 2: Exploratory Data Analysis (EDA)

### 🔍 EDA Performed

- Asked meaningful questions about the dataset before analysis.
- Explored the data structure, variables, and data types.
- Checked for missing values and duplicate records.
- Examined categorical and numerical variables.
- Identified trends, patterns, and potential anomalies.
- Used statistical analysis and visualizations to explore relationships.
- Checked potential data issues and validated the dataset for further analysis.

### 📌 Key Areas Explored

- Daily social media usage
- Primary social media platforms
- Relation Between Screen Time Before Sleep and Mental Health Score
- Relationships between social media habits and mental well-being
- Relation Between Daily Social Media Usage , Mental Health Score and Addiction Level
- Gender-wise Addiction and Mental Health Analysis
- Mental Health Score of Night Usage By Age
- Correlation Analysis
